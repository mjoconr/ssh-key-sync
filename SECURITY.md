# Security Policy

## Supported versions

Security fixes are provided for the latest stable release line. Older releases
may contain known flaws and should be upgraded before reporting behavior that
has already been fixed.

## Reporting

Do not report vulnerabilities in public issues.

Use the repository's **Security** tab and select **Report a vulnerability** to
open a private security advisory.

Never include live credentials, private keys, or production configuration in a
report. Redact identifying details where possible.

The project threat model, security invariants, and deployment controls are
documented in [docs/security.md](docs/security.md).
